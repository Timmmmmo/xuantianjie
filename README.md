# 玄天劫 · 刷不完的怪

东方玄幻题材的单人 **H5 幸存者（Survivors-like）** 小游戏 —— 无尽妖潮、飞剑自动索敌、
Combo 连杀、武器进化链、局外灵石养成。

> 灵感来自《魔兽争霸 III》RPG 地图「刷不完的怪」的核心循环：清怪 → 成长 → 推波。

## 立即游玩

**手机 / 桌面浏览器打开：**
https://Timmmmmo.github.io/xuantianjie/

## 玩法深度（v1.4 · 站阵 × 转职）

把「塔防的站位决策」翻译成「幸存者的走位决策」——不加操作键，只加策略。

### 剑阵守卫

战场四角各立一座剑阵，站入圈内蓄力 **1.1s** 激活；激活后阵内持续生效，
离开则保留 **5s 余威** 再衰减，逼玩家在阵与阵之间拉扯走位。

| 剑阵 | 增益 | 阵内效果 |
|------|------|----------|
| 烈焰剑阵（焰） | 攻击 +25% | 妖物持续燃烧 |
| 玄冰剑阵（冰） | 受击 -20% | 妖物大幅减速 |
| 天雷剑阵（雷） | 移速 +18% | 周期落雷 |
| 聚灵剑阵（灵） | 经验 +35% | 持续回血回灵 |

### 转职（3 系 × 3 分支）

境界 **5 / 10 / 15** 时，本应出的升级三选一改为一次转职抉择：

| 境界 | 阶段 | 内容 |
|------|------|------|
| 5 | 择道 | 三途择一：**剑道** / **玄法** / **体道** |
| 10 | 择法 | 本道之内择一法门精修 |
| 15 | 精进 | 再进一步，同法门可叠层至 Lv.2，也可改修他法 |

- 剑道：万剑归流（飞剑 +2）· 破锋无相（穿透 +2、暴击 +12%）· 剑气冲霄（剑气大幅强化）
- 玄法：业火焚天 · 九霄雷法 · 玄冰封天（各解锁/强化对应法术，并附带增益）
- 体道：血战不灭（气血 +80、残血增伤）· 荆棘铁壁（护盾 +60、反伤 +10%）· 守阵天君（剑阵范围/站阵伤害/余威全强化）

配套升级卡：**阵纹扩张**（剑阵范围 +15%）、**阵心通明**（站阵伤害 +18%）。
左上角 HUD 会显示当前剑阵与已入道途。

## 资源取舍（v1.6 · 五行灵晶 × 铸器台）

灵感取自「人族无敌」的灵石逻辑：**散落的素材是有限资源**，攒够能换一件带特殊攻击效果的专属装备；
若图快，随手拿它换普通装备——那就只有普通效果。

### 五行灵晶

| 来源 | 产出 |
| --- | --- |
| 小妖 | 14% 掉 1 颗，属性偏向当前波属性（45%），其余四行也会零星出现 |
| 精英 | 必掉 2 颗 |
| 妖王 | 必掉「五行灵髓」+ 2 颗灵晶 |

灵髓落地后弹出**五选一**：自选一行，直接得该属性灵晶 ×3。这是铸器路线的关键决策点。

### 铸器台（战斗中随时可开，开启即暂停）

| 类型 | 成本 | 上限 | 效果 |
| --- | --- | --- | --- |
| **专属装备** | 3 颗**同属性**灵晶 | 2 件 | **特殊攻击效果** |
| **寻常装备** | 2 颗**任意**灵晶 | 3 件 | 仅普通数值效果 |

**五件专属（对应五行）**：

| 行 | 名称 | 特殊攻击效果 |
| --- | --- | --- |
| 金 | 裂空金锋 | 飞剑穿透 +2；命中时剑气迸溅波及身周之敌 |
| 木 | 万藤长生 | 击杀吸血 +5；气血随时间自行滋长 |
| 水 | 玄冰寒渊 | 攻击必附寒毒减速；对精英有几率冰封定身 |
| 火 | 焚天炎狱 | 攻击必附灼烧；灼烧伤害大幅提升 |
| 土 | 磐石不动 | 受击反伤 +18%；护盾上限 +20 并随时间再生 |

**六件寻常**：凡铁锋刃（攻击 +15%）/ 疾风护腕（攻速 +12%）/ 厚土重甲（护盾）/
灵犀玉佩（暴击 +8%）/ 踏云靴（移速 +8%）/ 赤血丹（气血 +60）——**全部只有普通效果**。

### 为什么这是个真决策

- 灵晶总量有限，且掉落偏属性但不单一 ⇒ 不可能五系全走
- 攒 3 颗做专属 vs 花 2 颗立刻变强，是同一批资源的两条路
- 专属上限 2 件 ⇒ 五系只能取二，选路即定型
- 花灵晶时**优先掏最少的堆**，尽量不拆散你在攒的那一份

## 玩法

- **拖动屏幕任意位置** 移动；飞剑 / 环绕剑 **自动索敌**
- **剑气** 扇形爆发 · **御风** 加速无敌帧
- **连杀 Combo**：2.2s 窗口叠层，经验放大，10 / 25 / 50 有里程碑
- **武器进化链**：业火球→业火燎原、紫电→九天雷法、寒冰锥→千里冰封、周天剑阵→万剑归宗
- **三角色**：剑修 / 法修 / 体修
- **五行灵晶 · 铸器台**：攒同属灵晶铸专属（特殊攻击效果），或花碎晶换寻常（仅普通效果）
- **灵石商店**：永久强化（攻击 / 生命 / 移速 / 经验 / 灵石 / 剑胚 / 机缘）
- 无尽波次：零星刷新 + 正式波，每 3 波精英，每 5 波 Boss
