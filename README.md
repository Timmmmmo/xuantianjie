# 玄天劫 · 刷不完的怪

东方玄幻题材的单人 **H5 幸存者（Survivors-like）** 小游戏 —— 无尽妖潮、飞剑自动索敌、
Combo 连杀、武器进化链、局外灵石养成。

> 灵感来自《魔兽争霸 III》RPG 地图「刷不完的怪」的核心循环：清怪 → 成长 → 推波。

## 立即游玩

**手机 / 桌面浏览器打开：**
https://Timmmmmo.github.io/xuantianjie/

- 竖屏、横屏都支持；iPhone 可用 Safari「添加到主屏幕」获得真全屏体验
- 已做 PWA：可安装、可离线；Android Chrome 打开会提示「安装应用到主屏幕」
- 触控为主，桌面可用 WASD / 方向键 + 1·2 键

## 移动端优化（v1.3）

| 项 | 说明 |
|----|------|
| 动态摇杆 | 屏幕任意位置按下即在该处生成摇杆，跟手；抬指自动回到左下角 |
| 多指操作 | 一指移动 + 一指放技能互不干扰 |
| 视口修复 | `100dvh` + `position: fixed`，解决 iOS 地址栏跳动与橡皮筋滚动 |
| 安全区 | 刘海屏 / 灵动岛 / 手势条全部适配 `env(safe-area-inset-*)` |
| 后台暂停 | 切到后台或切标签时自动暂停，回来手动继续，不再「切出去就被打死」 |
| 性能自适应 | 按设备内存与实时 FPS 三档降级（DPR、雾团、粒子、毛玻璃、shadowBlur） |
| 屏幕常亮 | 战斗时用 Wake Lock 防止息屏 |
| 触感反馈 | 放技能 / 受击调用振动（设备支持则生效） |
| 可安装 PWA | manifest + Service Worker：全屏启动、离线可玩 |

## 玩法

- **拖动屏幕任意位置** 移动；飞剑 / 环绕剑 **自动索敌**
- **剑气** 扇形爆发 · **御风** 加速无敌帧
- **连杀 Combo**：2.2s 窗口叠层，经验放大，10 / 25 / 50 有里程碑
- **武器进化链**：业火球→业火燎原、紫电→九天雷法、寒冰锥→千里冰封、周天剑阵→万剑归宗
- **三角色**：剑修 / 法修 / 体修
- **灵石商店**：永久强化（攻击 / 生命 / 移速 / 经验 / 灵石 / 剑胚 / 机缘）
- 无尽波次：零星刷新 + 正式波，每 3 波精英，每 5 波 Boss

## 技术

纯 HTML5 Canvas 2D + 原生 JS，**零运行时依赖**。

```
index.html          入口
style.css           视觉与移动端适配
game.js             全部游戏逻辑
manifest.webmanifest / sw.js   PWA
assets/  icons/     美术与图标
docs/               项目章程、PRD、美术/UI 规范、QA 清单、质量报告
```

## 本地运行

```bash
python -m http.server 8080
# 然后打开 http://localhost:8080
```
