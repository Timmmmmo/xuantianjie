# 玄天劫 · 刷不完的怪

东方玄幻题材的单人 **H5 幸存者（Survivors-like）** 小游戏 —— 无尽妖潮、飞剑自动索敌、
Combo 连杀、武器进化链、局外灵石养成。

> 灵感来自《魔兽争霸 III》RPG 地图「刷不完的怪」的核心循环：清怪 → 成长 → 推波。

## 玩法深度（v1.4 · 站阵 × 转职）

把「塔防的站位决策」翻译成「幸存者的走位决策」——不加操作键，只加策略。

### 剑阵守卫

战场四角各立一座剑阵，站入圈内蓄力 **1.1s** 激活；激活后阵内持续生效，
离开则保留 **5s 余威** 再衰减，逼玩家在阵与阵之间拉扯走位。

| 剑阵 | 增益 | 阵内效果 |
|------|------|----------|
| 烈焰剑阵（焰） | 攻击 +25% | 妖物持续燃烧 |
| 玄冰剑阵（冰） | 受击 -20% | 妖物大幅减速 |
| 天雷剑阵（雷） | 移速 +18% | 周期落雷 |
| 聚灵剑阵（灵） | 经验 +35% | 持续回血回灵 |

### 转职（3 系 × 3 分支）

境界 **5 / 10 / 15** 时，本应出的升级三选一改为一次转职抉择：

| 境界 | 阶段 | 内容 |
|------|------|------|
| 5 | 择道 | 三途择一：**剑道** / **玄法** / **体道** |
| 10 | 择法 | 本道之内择一法门精修 |
| 15 | 精进 | 再进一步，同法门可叠层至 Lv.2，也可改修他法 |

- 剑道：万剑归流（飞剑 +2）· 破锋无相（穿透 +2、暴击 +12%）· 剑气冲霄（剑气大幅强化）
- 玄法：业火焚天 · 九霄雷法 · 玄冰封天（各解锁/强化对应法术，并附带增益）
- 体道：血战不灭（气血 +80、残血增伤）· 荆棘铁壁（护盾 +60、反伤 +10%）· 守阵天君（剑阵范围/站阵伤害/余威全强化）

配套升级卡：**阵纹扩张**（剑阵范围 +15%）、**阵心通明**（站阵伤害 +18%）。
左上角 HUD 会显示当前剑阵与已入道途。

## 本命灵石 × 流派宝石（v1.8）

灵感取自《魔兽争霸 III》RPG 地图「人族无敌」的装备合成：**灵石是角色绑定的有限资源**，
攒够同一系的主石能凝出**带特殊攻击效果的流派宝石**；若图快，
随手拿两颗换件**通用装备**——那就只有普通攻击效果。

### 每个角色有自己的专属灵石

| 角色 | 三系灵石（本命） | 对应五行 |
| --- | --- | --- |
| 剑修 | 赤锋石 / 疾风石 / 血煞石 | 火 / 木 / 金 |
| 法修 | 雷灵石 / 霜晶石 / 焚天石 | 金 / 水 / 火 |
| 体修 | 玄铁石 / 龙血石 / 磐石石 | 金 / 火 / 土 |

灵石**只掉本角色的那三种**，且三系大致均分 —— 天生不让你三系通吃。

| 来源 | 产出 |
| --- | --- |
| 小妖 | 0.6% 掉 1 颗（本命三系随机） |
| 妖王 | 必掉「**灵石精魄**」+ 1 颗灵石 |

精魄落地后弹出**三选一**：自选本命一系，直接得该系灵石 ×2。
这是全流程最重的决策点——**你想走哪一系，由你自己偏过去**。

### 九颗流派宝石（三阶配方）

凝练在「**炼宝台**」里完成，开启即暂停战斗。主石决定是哪一系，配料决定能到哪一阶：

| 阶 | 配方 | 强度 |
| --- | --- | --- |
| **初凝** | 主石 ×2 | 属性大增 |
| **化形** | 主石 ×2 + 任意本命灵石 ×1 | 属性 + 技能增益 |
| **圆满** | 主石 ×3 + 任意本命灵石 ×2 | 再长出**特殊攻击效果** |

推到圆满共需该系 **7 颗主石 + 3 颗配料**。而**流派位只有 2 席**——三条路只能取其二。

| 角色 | 流派宝石 | 圆满特效 |
| --- | --- | --- |
| 剑修 | 裂天剑罡（赤锋） | 飞剑 +1 · 命中溅射剑气 |
| 剑修 | 流云御风（疾风） | 御风后 3s 攻速 +30% |
| 剑修 | 噬血剑心（血煞） | 暴击时溅血爆裂 |
| 法修 | 九霄雷印（雷灵） | 击杀 20% 概率落雷 |
| 法修 | 太阴冰魄（霜晶） | 受寒毒影响者额外受 25% 伤害 |
| 法修 | 焚天赤篆（焚天） | 命中必附灼烧 · 灼烧增伤 |
| 体修 | 玄铁不坏（玄铁） | 护盾碎裂时爆发冲击波 |
| 体修 | 龙血战体（龙血） | 每 8s 回复 8% 气血 |
| 体修 | 磐石镇岳（磐石） | 受击 25% 概率震波 |

### 通用装备：只有普通攻击效果

凡铁锋刃（攻击 +15%）/ 疾风护腕（攻速 +12%）/ 厚土重甲（护盾）/
灵犀玉佩（暴击 +8%）/ 踏云靴（移速 +8%）/ 赤血丹（气血 +60）——
2 颗**任意**灵石一件，上限 3 件，**全部只有普通数值效果、不带任何特效**。

### 为什么这是个真决策

- 灵石总量有限，三系均分 ⇒ 想推满一系就必须让另外两系当配料
- 宝石只有 2 席 ⇒ 三条路只能取其二，选路即定型
- 「攒 7 颗主石推圆满」vs「花 2 颗立刻换件通用装备」，是同一批资源的两条路
- 花灵石时**主石留到最后掏**，尽量不拆散你正在攒的那一系

### 五行相生相克

每波妖物**统一带当前波属性**（第 1 波金 → 2 木 → 3 水 → 4 火 → 5 土 → 循环），
开局就报「第 N 波 · X 行妖潮」。**宝石**的五行参与判定，多颗时取**最优那一行**：

| 关系 | 倍率 | 飘字 |
| --- | --- | --- |
| 我克它 | ×1.35 | 克 |
| 它克我 | ×0.80 | 被克 |
| 它生我 | ×1.15 | 得生 |
| 我生它 | ×0.90 | 泄力 |
| 同属性 | ×1.00 | — |

相克：金克木 · 木克土 · 土克水 · 水克火 · 火克金
相生：金生水 · 水生木 · 木生火 · 火生土 · 土生金

**通用装备不参与五行**——它们只有普通效果，这一点在机制上也一致。
HUD 波次角标会在克制的波次高亮（↑）、被克的波次转暗（↓）。

### 数值校准（v1.8）

用无头探针实测过：满配无敌玩家跑 10 分钟（24 波、约 950 斩）自然掉落 **11 颗灵石**，
加上 4 次精魄自选（+8）合计 **≈19 颗**，其中最多一系 13 颗 ⇒
**刚好凝满 1 颗圆满，余量还能再开第二系一颗初凝**。
正常一局（约 15~18 波）落在 **1 颗圆满 + 1 颗初凝/化形**，符合预期。

调参集中在一处（`game.js` 的「经济调参」区块）：
`DROP_MOB 0.006` · `DROP_ELITE 0` · `DROP_BOSS 1` · `ESSENCE_GAIN 2` · `MELT_COST 2`。

宝石与通用皆满之后，富余灵石可走**灵石淬体**（2 颗任意 → 攻击 +2% / 护盾 +8，可重复），
收益明显低于宝石，所以决策重心仍在前面。

## 共鸣 · 多颗宝石的协同奖励（v1.9）

凝出第二颗（及以上）宝石时，会解锁「**共鸣**」——四条根据你的宝石搭配、转职道途、
灵石圆满情况自动算出奖励。面板在炼宝台底部四张卡，HUD 右上 chip 缩略显示已觉醒的。

| 共鸣 | 触发条件 | 加成 |
| --- | --- | --- |
| **本命归一** | 至少凝出 1 颗宝石 | 玩家全伤 +12% |
| **道途共鸣** | 任一宝石的元素 ∈ 转职五行集 | 该系对「所克」目标再 +25% |
| **跨阶归一** | 任一灵石推进至圆满（tier 3） | 该圆满特效整段伤害 ×1.5 |
| **破壁者** | 任意 2 颗宝石之间五行相克 | 对「未直接被克」的目标 +15% |

设计意图：
- **本命归一** 是入门奖励——让你一凝出宝石就感觉更爽。
- **道途共鸣** 让「转职 + 宝石」两个系统终于呼应。
- **跨阶归一** 鼓励你把一系推到圆满（瓶颈决策）。
- **破壁者** 让「铸哪两颗」也是真决策。

实战权衡（10 分钟一局）：
- 1 颗圆满 + 1 颗初凝 ⇒ 本命 + 道途通常能同时进（见这俩都是「有宝石就觉醒」）
- 把一系推到圆满 ⇒ 解锁破壁 + 道途 + 跨阶
- **没有共鸣**：你挑遍 9 系法门、跑满单局也至少有 2 条觉醒

## 派系灵石 v2.0（v2.0）

**主人要求**：「随机性强 + 派系归属 + 着力收集所属派系 → 超强增益」

### 资源池大改

| 维度 | v1.9（以前） | v2.0（现在） |
|------|-----------|-----------|
| 灵石池大小 | 9 颗（每角色 3 系 ×1） | **27 颗**（9 派系 ×3 颗） |
| 跨派系灵石 | 不会掉落 | **也会掉**（占比 ≈40%） |
| 本角色派系掉率 | 均分 1/3 | **加权 ×3**（实际占比 ≈60%） |

每派系 3 颗：玩家着力本角色某一派系时，有更多同派系素材可攒。

### 派系核心（终极奖励）

**机制**：攒齐 5 颗同派系灵石 → 解锁**派系核心**（永久被动 + 终极技能）。
9 个派系 ×1 个核心 = 9 个核心；最多同时装备 2 个。

| 派系 | 核心名 | 终极效果 |
|------|--------|----------|
| 赤锋派（火·剑） | 焚天剑阵 | 每 8 秒释放 8 道剑气，攻击 ×200% 范围伤害 |
| 疾风派（木·剑） | 御风化神 | 永久移速 +20%、御风 CD -50%、受击免伤 5% |
| 血煞派（金·剑） | 血月当空 | HP <30% 时全伤 ×2.0；击杀回血 +10 |
| 雷灵派（金·法） | 九霄雷域 | 每秒对周围 200 范围造成攻击 ×30% 雷电伤害 |
| 霜晶派（水·法） | 绝对零度 | 命中 50% 概率冰封 1.5 秒；受冰封目标受伤害 +30% |
| 焚天派（火·法） | 朱雀降世 | 灼烧伤害 ×3；灼烧扩散到周围敌人（200 范围） |
| 玄铁派（金·体） | 金刚不坏 | 护盾上限 ×2，再生 +5/s；受击 30% 完全免伤 |
| 龙血派（火·体） | 浴火重生 | HP 归零时满血复活一次（每局限一次） |
| 磐石派（土·体） | 镇岳之势 | 受击反伤 50%；每次受击护盾 +5 |

### 合成路径全图

```
捡到 1 颗灵石
  ├─→ 攒同派系（5 颗）→ 解锁派系核心 ★★★★★   ← 主推新目标
  ├─→ 凝本角色流派宝石（2-7 主石+配料）→ 流派宝石特效 ★★★（v1.9 保留）
  ├─→ 2 颗任意 → 通用装备 ★（v1.9 保留）
  └─→ 2 颗任意 → 灵石淬体 ★（v1.9 保留）
```

### 强化随机性

- DROP_MOB 0.006 → **0.008**
- DROP_BOSS 1 → **3**（妖王必掉 3 颗）
- DROP_ELITE 0 → **0.3**（精英 30% 额外 +1 颗）
- ESSENCE_GAIN 2 → **3**
- 新增 `SCH_PACK_DROP = 0.05`：精英 5% 概率掉「派系包」= 5 颗同派系（凑齐核心）

### 着力点设计

- 同派系灵石 5 颗即可解锁核心 —— **10 分钟内必解锁 1 个核心**
- 跨派系灵石可以熔炼淬体或换通用装备 —— **不掉价**
- 妖王必掉 5 颗同派系 + 3 颗随机 —— **凑齐核心的关键一跳**
- 派系核心**永久生效**（不像宝石要装槽位）—— **真正的专精奖励**

## 装备系统 v3.0（v3.0）

> 主人诉求：「增强随机装备掉落，背包，在背包中自动合成高级装备的逻辑功能，玩家只能带三个高级装备。」
> 完全替换 v1.7「通用装备」6 件灵石合成体系 —— 暗黑式装备链。

### 5 阶品阶 · 2→1 自动合成

```
白(普通) ─2→ 绿(精良) ─2→ 蓝(稀有) ─2→ 紫(史诗)★ ─2→ 橙(传说)★
                                          ↑ 高阶可装备 ↑
```

合成规则：**同 slot 同阶 + 至少 1 词条重叠 ⇒ 自动合高一阶**（顶级橙封顶）。
例：背包里 2 把白·青锋剑（都带「赤锋·炎」词条）→ 自动合成绿·青锋剑（保留火伤 + 加 1 词条）。

### 3 槽位 + 30 背包

| slot | 底材（随机） | 主属性 |
|------|--------------|--------|
| 武器 | 青锋剑 / 玄铁杖 / 龙骨爪 | 攻击 + 暴击 |
| 防具 | 玄铁甲 / 流云袍 / 龙鳞衣 | 生命 + 护盾 |
| 饰品 | 碧玉戒 / 紫金链 / 驱邪符 | 移速 + 急速/暴击率/吸血 |

- **3 高级槽位**：武器 / 防具 / 饰品各 1，**只能装紫和橙**（白绿蓝只能在背包里或卖）
- **背包 30 格**：满后白绿自动卖金币，紫橙提示丢弃

## 玩法

- **拖动屏幕任意位置** 移动；飞剑 / 环绕剑 **自动索敌**
- **剑气** 扇形爆发 · **御风（瞬步）** 冲刺无敌 0.6s，沿途留下带伤害的剑影
  - 手机上 **双击摇杆区** 也能瞬步，不用腾手去够技能键
- **连杀 Combo**：2.2s 窗口叠层，经验放大，10 / 25 / 50 有里程碑
- **武器进化链**：业火球→业火燎原、紫电→九天雷法、寒冰锥→千里冰封、周天剑阵→万剑归宗
- **三角色**：剑修 / 法修 / 体修
- **本命灵石 · 流派宝石**：每个角色三系专属灵石，三阶配方凝出带特殊攻击效果的流派宝石；花两颗任意灵石也能换通用装备（仅普通效果）
- **五行相生相克**：每波妖物统一带一行属性，宝石五行与它相克相乘 —— 这波该怎么打，看天吃饭
- **灵石商店**：永久强化（攻击 / 生命 / 移速 / 经验 / 灵石 / 剑胚 / 机缘）
- 无尽波次：零星刷新 + 正式波，每 3 波精英，每 5 波 Boss，**每 7 波尸潮涌**

## v7.0 · 三大爽点（合击 × 尸潮 × 瞬步狂血）

### A · 双兵合击
两把武器都到 Lv≥2 即解锁对应合击技，自动蓄能释放（不占操作位）；两把都觉醒 ⇒ **圆满档**，威力 ×1.5。

| 组合 | 合击 | 效果 |
|------|------|------|
| 业火 + 紫电 | 雷火劫 | 三柱天雷引燃业火，爆燃并附灼烧 |
| 业火 + 剑阵 | 焚天剑轮 | 八向火轮横扫穿透 |
| 业火 + 寒冰 | 冰火两仪 | 以己身为心的蒸汽爆，灼烧并冰缓 |
| 寒冰 + 紫电 | 玄冰雷引 | 雷链锁六敌，冰缓引雷 |
| 紫电 + 剑阵 | 千锋雷剑 | 十二雷剑自天而降 |
| 寒冰 + 剑阵 | 冰封剑狱 | 周身凝成剑狱，定身绞杀 |

一件装备可以同时投资多个派系词条 —— 这是**专精 vs 双修**的抉择：
3 件同派系 ⇒ 单武器觉醒 + 法门 Lv3（数值天花板）；双派混搭 ⇒ 解锁合击（形态天花板）。

### B · 尸潮涌 + 连锁击杀
每 7 波（避开 5 的倍数妖王波）从一侧灌入 `46+1.4×波次` 只低血尸傀，清完一次性给灵石包 + 蓝装 + 遗物 + 灵玉。
击杀有概率**引爆尸体向邻近敌人传导**，连杀越高链越长，尸潮里概率再 +12% —— 这是割草最爽的一秒。

### C · 瞬步 + 濒死狂血
- 瞬步：无敌 0.40s → **0.60s**，沿途每 0.07s 留一枚带伤害判定的剑影，冲过人群即造成杀伤
- 濒死狂血：血量 ≤25% 触发 5 息（攻速 ×2、伤害 +50%），22s 内置 CD

### D · 密度底座
每波怪量 `3+0.85w` → `4+1.35w`（10/20/30 波：11/20/28 → 18/32/48），涓流提速，同屏上限 80 → 110。
割草的本体是密度差，这一项是后面三套系统能不能"爽起来"的前提。
