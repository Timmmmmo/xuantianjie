# 美术与 UI 规范

## 风格锚点
**「暗色丝绸卷轴 × 灵力辉光」**
- 参考：暗色水墨 + 青绿法术光效 + 金色点缀（非写实，程序化矢量风格）
- 气质：肃杀、神秘、有压迫感，击杀时有爽快的灵光爆发

## 字体
- 中文：`"ZCOOL XiaoWei", "Noto Serif SC", "Source Han Serif SC", "Microsoft YaHei", serif`
- 数字/ID：`"JetBrains Mono", "Consolas", monospace`
- 标题字距略宽，正文紧凑

## 视觉分层
1. **地面**：暗色石板网格 + 微弱灵雾粒子
2. **角色/怪**：圆形/多边形剪影 + 发光描边 + 简单部件（耳/尾/甲）
3. **特效**：剑气弧、环刃、受击闪白、死亡灵爆、飘字
4. **UI**：半透明暗面板、金线描边、技能按钮径向冷却

## 角色视觉
- 玩家：青色发光圆核 + 外圈灵环 + 朝向剑尖指示
- 飞剑：小剑形几何体，尾迹粒子
- 妖狐：橙红圆体+双耳
- 石傀：灰岩方体
- 幽魂：半透明青紫飘带
- 血蝠：暗红小菱形×双翼感
- Boss：大体 + 头顶金环 + 名字条

## 动效原则
- 移动：摇杆死区 12px，插值平滑
- 攻击：飞剑有预备→出手→回收
- 受击：敌人闪白 80ms + 轻微击退
- 死亡：缩小+粒子爆+飘「灵力+X」
- 升级：暂停+卡片飞入+选中金光
