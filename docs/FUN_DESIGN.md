# 玩法可玩性 / 好玩性深化方案（讨论稿）

> 范围：**只讨论与排期**，本包不写玩法代码。基线 v7.8 已有：割草、克制、炼宝/装备/图鉴/试炼/尸潮/悬赏/合击。

---

## 1. 好玩性诊断（现在缺什么）

| 维度 | 现状 | 缺口 |
|------|------|------|
| 爽感密度 | 割草 + 连锁 + 尸潮 | **高光时刻**不够「可预期」——爽偶发 |
| 决策深度 | 配装/派系/宝石 | 中局后升级「趋同」，再战差异不足 |
| 操作表达 | 走位 + 两主动技 | 可秀身法的窗口偏少 |
| 目标节奏 | 波次/悬赏/试炼 | 长局 20+ 分钟缺少「段落感」 |
| 社交钩 | 周挑战/签到 | 无「晒操作/晒 build」传播帧 |

---

## 2. 增强方向（按 ROI）

### A. 自动必杀 / 清屏技（爽感密度）— **优先**
- 连杀 ≥N / 清潮进度满 → 自动「万剑归宗 / 雷池」清屏  
- **爽点**：憋大招的可视化进度 + 满屏特效高潮  
- **决策**：故意拉怪堆叠 vs 稳扎稳打  
- 工作量：中；不打断摇杆  

### B. 场景机关（走位表达）
- 灵泉回血 / 剑冢增伤 / 雷暴区持续伤害  
- **爽点**：地形成为武器/避难所  
- 工作量：中；需调平不坑新手  

### C. 精英前摇技（操作博弈）
- 砸地 AOE 预警圈、冲撞线、吐息扇形  
- **爽点**：读招闪避的「我能秀」  
- 工作量：中高（表现+判定）  

### D. Build 质变「流派觉醒」（长线）
- 同派系 3 件以上触发流派终极形态（变身/光环）  
- **爽点**：构筑兑现  
- 工作量：高（与现有觉醒/合击叠加要防爆炸）  

### E. 段落化「三幕天劫」（局内节奏）
- 每 8 波一幕：妖潮幕 → 妖王幕 → 试炼幕，幕间 5s 整备  
- **爽点**：长局有章节，死亡有故事感  
- 工作量：中（主要是波次编排）  

### F. 一键回放分享「高光 3 秒」（传播）
- 击杀高潮录 3s 静态序列导出  
- 工作量：高（浏览器录制限制）→ 可先做「高光截图卡」  

---

## 3. 推荐组合（2 个 Sprint）

| Sprint | 内容 | 目标 |
|--------|------|------|
| **S1** | **A 自动必杀** + **E 三幕天劫**（轻量） | 每局有明确高潮与段落 |
| **S2** | **B 场景机关** + **C 精英前摇** | 走位与读招有意义 |

D 流派觉醒放到 S3，避免与现有合击数值叠爆。  
F 传播帧可并行做「静态高光卡」（复用分享卡）。

---

## 4. A 自动必杀（若下包实现）规格草案

- 条件：`horde` 清潮进度 ≥100% **或** 连杀 ≥30  
- 表现：屏幕提示「天劫蓄势」→ 0.8s 预警 → 大范围伤害（约当前 ATK×8 全屏）  
- 冷却：每局 2 次 + 每幕 1 次充能  
- 埋点：`ult_cast` / `ult_wipe_kills`  

## 5. 三幕天劫规格草案

- 波 1–8「潮起」→ 9「狐王」→ 10–17「狂澜」→ 18「傀神」→ 18+「无尽」  
- 幕切换大字报 + 回 15% 气血  
- 与现有 15/30 试炼可错开  

---

## 6. 风险

| 风险 | 对策 |
|------|------|
| 必杀导致割草无脑 | 次数限制 + 需要「攒」 |
| 机关坑新手 | 前 3 波不刷机关 |
| 前摇技挫败 | 预警时间 ≥0.6s，低端机降特效 |
| 范围膨胀 | 严格按 S1/S2 切片 |

---

## 7. 结论

**可玩性主杠杆是「可预期的高光」与「有段落的长局」**，不是再堆系统。  
建议下个开发包只做 **A + E**，用数据（平均连杀、必杀次数/局、死亡波次分布）验证「好玩」是否提升。
