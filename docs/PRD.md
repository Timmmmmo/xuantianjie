# 《刷不完的怪·玄天劫》产品规格（PRD）

## 1. 核心循环
```
进入战场 → 妖潮围攻 → 操作击杀 → 获得灵力/经验
    ↑                                    ↓
 死亡/通关 ← 挑战Boss ← 技能/法宝强化 ← 升级抉择
```

**一句话目标**：在无尽妖潮中活得更久、清得更狠、Build 更爽。

## 2. 战斗系统
### 2.1 操作
- **移动**：左侧虚拟摇杆（触控）/ WASD（键盘）
- **普攻**：自动索敌最近妖物，飞剑环绕攻击
- **主动技能**：右侧 2 个按钮
  - Q/技能1：剑气纵横 —— 扇形穿透伤害
  - W/技能2：御风身法 —— 短暂加速+无敌帧
- **被动**：环绕飞剑（攻速/数量随成长）

### 2.2 属性
| 属性 | 说明 |
|------|------|
| 生命 | 归零死亡 |
| 灵力（法力） | 技能消耗，缓慢回复 |
| 攻击 | 飞剑/技能伤害基数 |
| 攻速 | 飞剑出手间隔 |
| 移速 | 走位 |
| 暴击率/暴伤 | 爆发 |
| 吸血 | 击杀回复 |
| 范围 | 飞剑/技能半径 |

### 2.3 成长（每局重置，高可玩性来源）
- **等级**：击杀获得经验，满级弹出 3 选 1
- **升级选项池**（至少 15 种，随机3个）：
  - 攻击+、攻速+、生命+、移速+
  - 飞剑+1、环绕半径+
  - 剑气扇形角度/伤害+
  - 暴击、吸血、冷却缩减
  - 灵力回复、受击护盾、经验加成
  - 「剑心通明」：飞剑附带穿透
  - 「血祭」：低血量增伤
  - 「妖丹」：击杀额外经验
- **法宝掉落**：精英/Boss 掉落，三选一或直接拾取
  - 例如：诛仙剑（+穿透）、玄武盾（护盾）、疾风靴（移速）、紫电锤（链式闪电）

## 3. 妖潮（怪物）设计
### 3.1 刷怪规则
- 从屏幕外圈出生，向玩家涌来
- **基础波次**：每 25 秒一波（波次越高怪越强）
- **持续 trickle**：波间隙仍有零星刷新，保证「刷不完」
- **精英**：每 3 波出现 1–2 只高血高伤精英
- **Boss**：每 5 波出现大妖，击败给大额奖励

### 3.2 妖物图鉴（初期）
| 类型 | 行为 | 特点 |
|------|------|------|
| 野狐妖 | 直追 | 低血，量大 |
| 石傀儡 | 直追 | 高血慢速，皮糙肉厚 |
| 幽魂 | 直追 | 中速，死后裂成小幽魂 |
| 血蝠 | 环绕逼近 | 快速，伤害中 |
| 妖狼 | 直追 | 中等，成群 |
| 玄铁傀儡(Boss) | 直追 | 大体积，周期砸地AOE |
| 九尾狐妖(Boss) | 直追+召唤 | 召唤小狐，高伤 |

### 3.3 难度曲线
- 怪物 HP：`base * (1 + 0.18 * wave) * (1 + 0.02 * wave^1.35)`
- 怪物 ATK：`base * (1 + 0.12 * wave)`
- 数量：`3 + floor(wave * 0.8)` 每波
- 玩家预期：无 build 约撑到 8–12 波；好 build 到 25+

## 4. 局内节奏
| 时间 | 事件 |
|------|------|
| 0s | 开局，1级，基础飞剑×1 |
| 0–20s | 教学：摇杆躲、飞剑自动打 |
| 25s | 第1波正式潮 |
| 50s | 第2波 |
| 75s | 第3波 + 首个精英 |
| 100s | Boss（第4波）或按波次计 |
| 持续 | 升级三选一、法宝、更强波次 |

## 5. 局外（轻量）
- 记录：最高波次、最高击杀、最久存活
- 解锁称号：炼气/筑基/金丹/元婴/化神（按最高波）
- 「再来一局」为主按钮

## 6. 文案基调
短、玄、有劲。技能与妖名用中文玄幻语感，避免西幻词。

## 7. 体验目标（产品验收）
- 前 30 秒：会动、会打、会升级
- 前 3 分钟：形成 Build 方向
- 死亡时：知道自己怎么死的，且想再来
