# 《刷不完的怪·玄天劫》项目章程

## 一、项目定位
- **源玩法**：魔兽争霸RPG地图「刷不完的怪」核心循环 —— 无尽波次怪物刷新，玩家在局内成长、清怪、推波
- **形态**：单人竖屏/横屏兼容的 H5 手机游戏（可直接在移动浏览器游玩）
- **题材包装**：东方玄幻 / 修真 —— 妖潮围城，修士御剑守心
- **目标**：可玩性高（单局 8–15 分钟心流），可反复开局（build 差异化）

## 四、技术选型
- 纯 HTML5 Canvas + 原生 JS，零外部依赖
- 触控虚拟摇杆 + 技能按钮（兼容键盘 WASD/1/2/3）
- localStorage 存档（最高波次、解锁内容）
- 目标：中低端手机 60fps，逻辑/渲染分层

## 五、成功标准
1. 开局 10 秒内理解目标（活下去、清妖潮）
2. 每波有成长感（等级/技能/装备）
3. 操作手感：摇杆跟手、攻击有反馈
4. 死亡后有「再来一局」冲动
5. 玄幻味：命名、色彩、粒子、音效文案统一
