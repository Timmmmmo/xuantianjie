# 质量报告 · 玄天劫 v1.3（手机端适配 + 上线）

**验收结论：通过（已上线 `https://timmmmmo.github.io/xuantianjie/`）**

## 本轮改动
| 类别 | 内容 |
|------|------|
| 交互 | 摇杆由「固定左下角」改为「屏幕任意位置按下即生成」；Pointer Events + 指针捕获；多指不互相打断 |
| 稳健 | 切后台/切标签自动暂停（新增 `pause` 状态与暂停面板）；`blur` 释放摇杆 |
| 视口 | `100dvh` + `body{position:fixed}`；`visualViewport` 监听；横竖屏切换防抖 |
| 性能 | 设备档位预判 + 实时 FPS 三档自适应；背景渐变缓存；`level-badge` 选择器缓存；低端机关闭 `shadowBlur`/毛玻璃/动画 |
| PWA | `manifest.webmanifest`、`sw.js`（导航网络优先 / 静态缓存优先）、图标 5 枚（脚本生成） |
| 体验 | Wake Lock 屏幕常亮、`navigator.vibrate` 触感、音效开关与记忆、全屏按钮、禁长按/双击缩放 |
